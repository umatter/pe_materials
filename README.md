# Prompt Engineering for Economists: Day 2 materials

Data analysis with AI and R. Student materials for Day 2 of *Prompt Engineering for Economists*
(University of St. Gallen, autumn 2026), taught by Ulrich Matter.

**Start here: [SETUP.md](SETUP.md)** (OpenRouter key, Colab, Nuvolos, your own machine, pi).

## Open in Google Colab

You can run each notebook directly in your browser using Google Colab. You need a Google account (free)
to use Colab. Colab opens a notebook from GitHub with the warning "This notebook was not authored by
Google": click **Run anyway**. The notebooks open in Colab's R runtime.

## Contents

- `R/or_chat.R`: the helper all blocks use. `or_chat()` sends a prompt to a model through
  [OpenRouter](https://openrouter.ai) and returns the reply; `parse_json_reply()` reads JSON
  replies. It reads your key from the environment variable `OPENROUTER_API_KEY`; never write a
  key into a file. Tests: `tests/test_or_chat.R`.
- `b1/` … `b4/`: one folder per block. The notebooks are generated by each folder's `build.py`
  with `tools/nbtools.py`; edit those, not the `.ipynb`.
