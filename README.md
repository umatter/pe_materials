## Contents

- `R/or_chat.R`: the helper all blocks use. `or_chat()` sends a prompt to a model through
  [OpenRouter](https://openrouter.ai) and returns the reply; `parse_json_reply()` reads JSON
  replies. It reads your key from the environment variable `OPENROUTER_API_KEY`; never write a
  key into a file. Tests: `tests/test_or_chat.R`.
- `b1/` … `b4/`: one folder per block. The notebooks are generated by each folder's `build.py`
  with `tools/nbtools.py`; edit those, not the `.ipynb`.
